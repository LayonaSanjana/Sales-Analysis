# Sales-Analysis

## Overview
This project focuses on analyzing sales data from the Diwali season using Python and Excel. It leverages data manipulation and visualization techniques to derive insights into sales trends and performance.

## Key Features
- **Data Analysis with Python:** Utilized NumPy and Pandas for data manipulation and analysis.
- **Visualization:** Used Matplotlib and Seaborn to create insightful visualizations such as bar charts, line plots.
- **Excel Dashboard:** Developed an interactive dashboard in Excel to present key metrics and trends visually.

## Technologies Used
- Python
  - NumPy
  - Pandas
  - Matplotlib
  - Seaborn
- Excel (for dashboard creation)
